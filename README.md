# Monte Listing Pro

Quero transformar meu protótipo existente em um site profissional para a imobiliária Marangoni Despachante Imobiliário, de Monte Santo de Minas, MG.

INSTRUÇÕES IMPORTANTES:

Analise todos os arquivos anexados antes de fazer alterações.

Preserve ao máximo o design visual original: cores, tipografia, espaçamentos, cabeçalho, rodapé, cartões de imóveis, filtros e janela de detalhes.

Não recrie o site com um design genérico e não remova funcionalidades existentes.

Se o projeto estiver em HTML, CSS e JavaScript puro, adapte-o à estrutura de aplicação suportada pelo Lovable, mantendo a aparência e o comportamento.

O site deve funcionar bem em computadores, tablets e celulares.

Mantenha todo o conteúdo em português brasileiro.

Não invente imóveis, preços, endereços, avaliações, depoimentos ou dados de contato reais. Identifique claramente qualquer dado de demonstração.

Não publique o site nem conecte meu domínio ainda.

Primeiro, analise os arquivos e apresente um resumo da estrutura atual, dos recursos existentes e das mudanças necessárias. Depois, faça a adaptação visual e funcional sem começar o backend.
